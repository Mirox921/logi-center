# Logi Center roadmap

- Keep the QML interface and shared hardware services stable; GTK recovery is archived externally.
- Extend hardware support only with model-specific protocol evidence, guarded writes and readback.
- Complete the remaining physical validation described in [device support](docs/backend-support.md)
  and [QML parity](docs/qml-parity.md).
- Keep source, wheel, user-local and Arch installations consistent through packaging regression checks.

Repository layout and development commands: [architecture](docs/development/architecture.md).
