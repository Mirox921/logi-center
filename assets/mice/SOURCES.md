# Model artwork sources

## EWEADN S9, 2026-10-29

`eweadn-s9-original.svg` is the user's supplied Flame Red Mouse vector, integrated
with explicit permission for this project. The source is preserved unchanged.
`eweadn-s9.svg` is the reproducible Qt derivative produced by
`scripts/prepare_eweadn_svg.py`, replacing unsupported clip paths with bounded
masks. No raster is embedded. Model matching requires the confirmed S9 model
identifier in addition to USB VID/PID; the shared receiver alone is insufficient.
This is the supplied visual reference, not a manufacturer CAD accuracy claim.
