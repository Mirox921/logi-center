# Device artwork sources and licenses

All PNGs in `generated/` and `fallback.png` / `fallback@2x.png` are original
Logi Center layered 2D class illustrations. Author: Logi Center contributors.
License: MIT (assets/LICENSE-MIT.txt). Source: `illustrations/` in this repository;
no manufacturer photographs, store images, product textures or third-party
meshes are copied. Transparent outputs are 512×320 / 1024×640. They are built
offline and loaded as assets; the renderer is not installed as runtime code.

| Source | Conditions / current content |
|---|---|
| user | Local PNG/WebP/restricted SVG chosen by the user, or dropped into `device-images/<physical-identity-hash>.*`. Absolute priority. Private and not exported. Old managed `device-artwork/` preferences remain readable. |
| exact-model | One user-approved project-authored G502 HERO SVG selected by the G502 HERO USB product ID. It is product-level artwork; no hardware revision or exact button dimensions are claimed. Future revision-specific art must also match a confirmed revision. |
| system | Empty registry. A future entry may point to a legally installed Piper/libratbag resource with exact identity. Do not copy a similar model from an external package into this repository. |

Canonical names use hyphens (`mouse-gaming@2x.png`, `keyboard-65@1x.png`). Legacy
underscore file names are understood by the provider for upgrade compatibility.
The full file/source list and rendered sheets are generated by
`python scripts/icon_gallery.py` into `docs/screenshots/redesign/icons/`.

## 2026-10-25 stage 4

All 50 PNG files are generated by the project's offline Cairo tool, MIT.
Added display-hdmi and display-dp variants; a generic display-audio icon remains
for a confirmed display without known connector subtype. Transport alone selects
the neutral round Bluetooth audio module, never a speaker. Built-in audio uses
a slim perforated panel; audio-unknown uses a neutral waveform instrument; unknown
uses a tall chamfered instrument. An untyped internal pointer intentionally
aliases unknown, not touchpad: positive input evidence is required. The alias is
labelled generalized artwork and is excluded from different-class silhouette tests.

Keyboard materials are graphite, not product-specific key colors. Shared physical
scale applies within mouse and keyboard families. User/exact/system precedence
is unchanged. New measured sheets and actual relative file paths/SHA-256 hashes:
`docs/screenshots/redesign/illustrations/iteration4/after/sources.md`.

## Iteration5, final user-selected shape

Mouse outer contours follow the project-authored iteration4 references supplied
by the user. C2 Bezier spans remove the old waist step; button zones are light
fields inside the same shell. User explicitly requested two integrated side
buttons for wireless/gaming artwork; plain/compact remain without them. This
is class illustration, not protocol evidence or an exact K7/G502 product claim.
Side protrusion <=0.6mm, centres13mm apart. Wheel is low-contrast rubber.

Added pointer-generic@1x/@2x.png. mouse-builtin aliases that1.4:1 neutral touch
surface; confirmed touchpad is1.55:1 with click zone/texture. The rejected fading
palm-rest rectangle is absent. Only faint lower/side physical corner traces
remain. No power dot, perforation or third-party image. All52 PNGs: project/MIT.
Baseline references under iteration5/reference/iteration4/ are copies of this
project's own earlier MIT illustrations, not manufacturer photos.

## Approved G502 HERO artwork

`exact/g502-hero.svg` is a clean, editable project-authored vector (MIT). The
user approved the proposal from `docs/artwork-proposals/`. The same SVG is used
by the Dashboard and QML button editor; the old `diagrams/g502.svg` and generic
PNG remain available for rollback and other models. `exact/models.json` stores
the confirmed product ID, native 480×440 canvas, visual bounds and the existing
`mouse_models.G502` anchor family. There is no embedded bitmap, copied logo or
manufacturer image. The product's physical revision and exact anchor placement
have not been verified against a calibrated reference photo.

## User-supplied G502 SVG set, 2026-10-28

The four files named in `exact/g502-inputs.sha256` were supplied and explicitly
approved by the user for integration. Packaged copies are byte-identical to
the supplied files; they retain their editor metadata, styling and LC mark.
They contain vector paths/text, no embedded raster product photograph. Author
and upstream license were not supplied; the earlier project/MIT notice does
not apply to these four files. Redistribution rights are not established.

`exact/models.json` selects the top image for wired G502 HERO c08b and the
G502 wireless IDs c08d/407f documented by the installed libratbag device data.
Positive wireless/Bluetooth/2.4G transport chooses the wireless variant; USB
chooses the cable variant. Transport variants do not merge physical devices.
Button editor side images and normalized anchors are separate metadata in
`mouse_models.G502_ART`; no asset is modified to draw interactive controls.
G502 X is excluded. `g502-hero.svg`, `g502-hero-legacy.svg` and the earlier
project-authored side candidate remain available for rollback.

## Qt compatibility derivatives, 2026-10-28

`exact/g502-top-wired-qt.svg` and `exact/g502-top-wireless-qt.svg` are generated
from the corresponding supplied top views by `scripts/prepare_g502_svg.py`.
Original supplied files and their SHA-256 manifest remain unchanged. Native
path data, transforms, dimensions, material RGB values and LC mark are retained.
Unsupported Qt clipPath uses become equivalent white/even-odd luminance masks;
opaque rgba gradient stops use rgb syntax. A bounded page mask preserves
coloured details in the Qt masked-group renderer. These copies inherit the
supplied files' unresolved licensing provenance; no new ownership is asserted.

Dashboard and button editor now share these compatible top SVGs. Side assets
remain byte-identical supplied files. Reference PNGs in
`docs/screenshots/g502-svg-compatibility/` are offline librsvg renders of the
original supplied SVGs, used to validate contours and material colours, not
production raster substitutes. `scripts/check_g502_svg.py` renders the actual
SVGs in Qt and checks transparency, grayscale gradients and coloured details.

The separate MIT license text is preserved in `assets/LICENSE-MIT.txt`.
