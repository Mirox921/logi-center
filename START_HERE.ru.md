# Logi Center v0.5.1 — запуск

Qt6/QML — единственный интерфейс текущей версии. Приложение предназначено
для Linux; архив содержит исходники, а не автономный AppImage.

## Зависимости

Для Arch Linux:

```bash
sudo pacman -S --needed python python-yaml python-gobject pyside6 qt6-declarative qt6-svg qt6-wayland
```

PyGObject нужен Gio/GLib D-Bus readers; GTK4/libadwaita не требуются.
В другом дистрибутиве используйте эквивалентные пакеты. Backend устанавливаются
отдельно по необходимости: libratbag, Solaar, HeadsetControl, PipeWire/PulseAudio
и прочие. Не запускайте GUI от root ради обхода прав HID.

## Без установки

Проверьте SHA256SUMS, распакуйте архив и откройте терминал в папке с app.py:

```bash
python app.py --version
python app.py
```

Симуляция без реального оборудования:

```bash
python app.py --simulate
```

## Пункт меню приложений

```bash
python install.py
```

Установщик без root обновляет ~/.local/share/logi-center,
~/.local/bin/logi-center и desktop entry. **Повторяйте установку после
обновления исходников**, иначе меню продолжит запускать прежнюю установленную
копию. Настройки, черновики и личные backup-файлы не удаляются.
Системный пакет Arch и пользовательская установка — разные способы; выберите
один, чтобы старый пользовательский launcher не перекрывал новый системный.

## Ограничения и данные

В архив не входят домашние настройки, серийные номера, пользовательские макросы,
записи микрофона и частные аппаратные копии. Системные backend и udev permissions
не устанавливаются и не меняются автоматически.
Неподтверждённые возможности остаются отключёнными. Реализация, mocks и
аппаратное подтверждение различаются в документации:

- [Возможности и проверки](docs/qml-parity.md).
- [Зависимости backend](docs/backend-support.md).
- [S9 и ограничения native macros](docs/eweadn-s9.md).
- [История перехода и архив GTK](docs/qml-cutover.md).
- [Сборка Arch](packaging/arch/README.md).

--ui qml сохранён для совместимости. Для --ui gtk нужно отдельно восстановить
архивную GTK-версию; в текущей программе GTK нет.
